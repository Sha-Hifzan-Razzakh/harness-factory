# Relaymail documentation

Relaymail is an API for sending transactional email: receipts, password resets, alerts.

The current API is **v2**. Start with [Authentication](https://docs.relaymail.example/v2/authentication), then
[Sending email](https://docs.relaymail.example/v2/sending).

- [Rate limits](https://docs.relaymail.example/v2/rate-limits)
- [Webhooks](https://docs.relaymail.example/v2/webhooks)
- [Errors](https://docs.relaymail.example/v2/errors)
- [Changelog](https://docs.relaymail.example/changelog)

API v1 was retired on 31 March 2026. Its pages stay online for reference under
[/v1](https://docs.relaymail.example/v1/overview) and are no longer updated.
