# API v1 retires on 31 March 2026

*1 December 2025*

API v1 will stop accepting requests on 31 March 2026. Moving to v2 takes most teams an afternoon: change the base
URL, move the key to the `Authorization` header, and update your webhook signature check.

The v1 documentation will stay online, marked as retired, for anyone maintaining old integrations.
